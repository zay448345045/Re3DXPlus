# iOS executable build (arm64)

This is a compile-and-link helper, not an app packager. It creates only `phys_rc.o` and the unsigned `WMMT` executable in a **new**, explicitly named output directory. It never signs, exports an IPA, contacts a device, or includes game assets. Failed compilation may leave partial output; choose another new directory for the next attempt.

## Prerequisites and preparation

* macOS, Xcode with the iPhoneOS SDK and `xcrun`; the active Xcode selection is used by default. To select another installation, set `DEVELOPER_DIR` yourself.
* The repository omits derived headers and `src/phys/phys_rc.c`. The script lists missing required inputs before creating output. Legally obtain all original inputs yourself and prepare the derived files in a **disposable copy** of `ports/ipad`; do not overwrite originals. The existing `tools/gen_from_original.sh` documents its Python dependencies, source inputs and optional `--phys` generation, but writes into its project tree, and may require additional files or tools. Review it before use.
* Some required headers (including `meterdb_v2.h`, `racing_lamp_data.h`, `story_cutin_data.h`, and `time_texture.h`) are not shown as outputs of that generator. Whether all required files can be regenerated from the supplied sources is not established; obtain or reconstruct them lawfully and verify their provenance. The preflight is not a guarantee that every transitive dependency is present.
* Runtime assets, including any physics image, are separate from compilation and must be legally prepared by the user. They are not included or generated by this helper.

## Build

From the prepared copy's `ports/ipad` directory, with `build-output` not yet present and its parent already present:

```sh
sh tools/build_ios.sh build-output
# Optional alternative Xcode selection:
# DEVELOPER_DIR=/path/to/Xcode.app/Contents/Developer sh tools/build_ios.sh another-new-output
```

The helper targets arm64, iOS 16.0 minimum, and the iPhoneOS SDK, using the same source and framework list as the prior isolated compile. Check the resulting executable as needed with `xcrun vtool -show-build build-output/WMMT`. This produces no installable app; signing, packaging, resources and device deployment are outside its scope. A complete build has not been verified from this repository alone.
